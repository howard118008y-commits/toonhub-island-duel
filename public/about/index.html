關於與隱私

一座島，
很多種個性。

Card & TW ＆ Game 是以臺灣地區角色為主題的免費單機網頁自走棋。把熟悉的早餐、通勤、咖啡、港口與生活笑點，變成可以招募與搭配的卡牌角色。

目前可以玩到什麼？

本版包含 24 種角色、6 個陣營、4 階商店、三合一金卡與 10 輪單機冒險。你負責招募和排陣，角色自動戰鬥。介面與教學使用繁體中文，支援電腦與手機瀏覽器。

遊戲免費且免註冊，目前沒有付費購買、真人配對、雲端帳號或排行榜。首次開啟需要網路載入頁面與素材；目前不提供保證離線可用的模式。

角色與玩法的來源

角色是以臺灣生活文化與常見地區印象為靈感的原創趣味設定。每位角色都有地區名稱、職業、插畫和台詞。這些內容不代表實際居民的特質，也不應用來評價某個人的出身或能力。

玩法參考自走棋常見的招募、羈絆、站位、三合一與自動戰鬥概念，改寫為 24 種角色的單機十輪闖關。研究過程參照《爐石戰記》英雄戰場官方介紹與玩家討論，但本遊戲不是 Blizzard 或《爐石戰記》的官方作品，也沒有合作或背書關係。

頁面與遊戲使用本專案角色素材，並未採用 Blizzard 的角色、美術或程式碼。規則研究與測試記錄可在設計資料、平衡驗證報告與驗收記錄查閱。

角色數值與玩法以目前網站版本為準。測試與模擬用來發現問題，不代表保證勝率或真人玩家的體驗評分。

你的資料放在哪裡？

遊戲進度只存於這個瀏覽器

遊戲使用瀏覽器的本機儲存空間（localStorage），保留隊伍、金幣、生命、回合、商店與戰鬥結算。存檔識別名稱是 island-autobattler-v1。目前沒有把遊戲進度上傳到本專案的帳號服務或資料庫。

同一裝置上的不同瀏覽器不會共用存檔。清除本網站資料後，進度會消失；私密瀏覽或儲存被封鎖時，遊戲會顯示無法儲存的提示。按遊戲內「重開」並確認，會開始新的冒險並取代本機進度。

沒有另加追蹤分析或廣告工具

目前遊戲本身沒有加入第三方分析、廣告像素或行銷追蹤 Cookie。網站使用系統中文字體，不另外請求第三方字體服務；角色圖片與程式由本網站路徑提供。

網站代管與外部連結

網站由 GitHub Pages 代管。瀏覽網站時，GitHub 可能依其服務運作與隱私聲明處理 IP 位址等連線資訊；這與遊戲的本機存檔不同。點擊 GitHub、官方資料等外部連結後，適用該網站的資料處理方式。

回報問題與確認版本

程式與修改記錄公開於GitHub 專案。若遇到操作或顯示問題，可以透過專案問題回報頁描述裝置、瀏覽器、發生輪次與操作步驟；使用 GitHub 回報需要 GitHub 帳號，遊玩本身不需要。

請不要把個人敏感資料放進公開回報。重新開始或清除資料前，先記下問題畫面與情況，較容易重現。
