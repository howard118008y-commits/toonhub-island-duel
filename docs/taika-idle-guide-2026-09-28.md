# 台卡五秒閒置引導

日期：2026-09-28。本輪狀態：程式、自動化、桌機與窄版瀏覽器驗收通過；正式建置與 SEO 檢查通過。

## 提示做什麼

- 預設開啟。玩家停下操作滿5秒後，提供一項本機建議與原因，並高亮畫面上真正可操作的目標。
- 提示不自動買牌、部署、出售、換位或開戰；玩家必須親自操作。它是依目前局面的啟發式規則，不保證最優解或勝率。
- 是否開啟僅存在此瀏覽器的`taika-guide-enabled-v1`（`on`／`off`）；缺省為開，不主動寫入預設值，不增加雲端帳號或追蹤。
- 等待期間的滑鼠移動、點擊、按鍵與捲動重新計時；提示已出現後滑鼠可移往關閉鈕或目標，不會一移動就消失。
- 真正按下、鍵盤操作、捲動或遊戲動作會收起提示；關閉本次提示後，須有新活動才重新等待5秒。
- 拖曳、交易處理、戰鬥、隱藏頁籤、對話框、手機角色抽屜及開箱動畫期間不顯示；回到可操作畫面再等完整5秒。
- 靜止未開木盒、大廳、戰後結果也能指向該畫面的主要按鈕。空隊且無錢可招募時，可指返回大廳，不新增金幣或改動規則。

## 建議與介面界線

建議函式只讀本機局面，輸出原因與語義目標（控制按鈕、商店卡、已擁有角色或棋盤空位）；UI必須再核對目標存在且可操作，不能高亮不存在或已停用的控制。
招募時優先領可接收的免費援軍、補上場空位；獎勵塞住時先找合法騰位操作。接著比較手牌替換、可負擔的招募與三合一、相鄰技能站位，再考慮有保留招募預算的升級／刷新，最後才提示準備開戰。不同畫面只提示當下的開箱、開始／繼續、回旅店或下一輪控制。

估分包含攻血、護盾、技能、相鄰位置和不同角色羈絆；它不模擬隨機戰鬥、不讀取外部資料，也不預測勝率。只在分數明顯改善時建議換位，平手保留現況；本輪已刷新／升級的紀錄用於避免反覆勸玩家花錢。已選取別張牌時會先指向取消選取，避免建議另一張牌意外觸發換位。

提示使用既有狀態列，桌機與手機皆不增加浮動遮罩；出現時暫時取代狀態文字。木盒／大廳提示置於畫面頂部。每次提示可關閉，遊戲選單可儲存引導開關。
